# Dependabot review — 2026-10-02

Reviewed all 63 open alerts against main, application usage, GitHub advisory details, and every exact package instance in the lockfile. 44 are resolved by dependency updates; 19 still match vulnerable version ranges. No alerts were dismissed. GitHub labels build dependencies runtime because react-scripts is in dependencies; deployment serves static build output on GitHub Pages. Developer/build risks still matter.

Compatible updates were installed without audit --force. Two targeted overrides patch serialize-javascript (CommonJS API retained; requires Node 20+, matching CI) and Underscore pinned by jsonpath. npm audit package counts include affected parents and differ from individual Dependabot alert counts: 46 before, 23 after.

The development wrapper restores the documented [publicPath trailing-slash workaround](https://github.com/advisories/GHSA-g84c-rxfj-3j2c), binds to 127.0.0.1 by default, restricts allowedHosts, and adds same-origin CORP. It preserves CRA configuration and HMR. Existing remote/LAN development access becomes restricted. Direct react-scripts start bypasses these mitigations; use npm start.
